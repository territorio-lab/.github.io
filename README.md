TERRITÓRIO LAB — SITE ESTÁTICO

Estrutura:
- index.html: página inicial
- style.css: identidade visual e estilos de todas as páginas
- script.js: filtros, menu e ano automático
- projetos/: páginas individuais de projetos
- laboratorio/: páginas de processo e método

Para usar: copie o conteúdo desta pasta para a raiz do repositório territorio-lab.github.io, preservando as pastas projetos/ e laboratorio/. Abra index.html localmente para testar. Publique com commit + push no GitHub Desktop.

IMPORTANTE: os textos e composições visuais das páginas internas são modelos provisórios. Troque-os pelos dados, imagens e links reais dos seus projetos. O endereço de e-mail na página inicial também deve ser atualizado antes de publicar.
